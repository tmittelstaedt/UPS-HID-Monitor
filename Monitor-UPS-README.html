UPS Monitor PowerShell Script – Documentation

1. Overview

The UPS Monitor PowerShell Script is a Windows-based utility that:

  • Monitors UPS (Uninterruptible Power Supply) status.
  • Works with local UPS devices via Windows WMI (Win32_Battery) or remote UPS devices via a Network UPS Tools (NUT) server.
  • Displays a system tray icon with color-coded status:
    • Green – UPS is online (AC power present)
    • Red – UPS is on battery
    • Gray – Status unknown
  • Optionally runs a TCP server to provide UPS status in JSON format for remote monitoring.
  • Can initiate a system shutdown if AC power is lost for a configurable delay.

2. Features

FeatureDescription
Tray IconShows UPS status with color coding and tooltip text.
Local UPS SupportUses Windows WMI to read battery status.
NUT Server SupportQueries a remote UPS via TCP port 3493.
Shutdown TimerAutomatically shuts down the system after a set delay if AC power is lost.
TCP Status ServerServes UPS status as JSON for integration with other tools.
Resource CleanupDisposes of icons and stops TCP listener on exit.

3. Requirements

  • Operating System: Windows 10, 11, or Windows Server with PowerShell 5.1+ or PowerShell 7.x.
  • Permissions: Administrator rights required for shutdown functionality.
  • Optional: Network UPS Tools (NUT) server for remote UPS monitoring.

4. Configuration Parameters

VariableDefaultDescription
$NutServer$nullIP or hostname of NUT server (leave $null for local UPS).
$UpsName$nullUPS name on NUT server.
$shutdownDelaySeconds300Delay before shutdown after AC loss (in seconds).
$enableTcpServertrueEnable/disable TCP status server.
$tcpPort5555TCP port for status server.

5. How It Works

  1. Initialization – Loads .NET assemblies, creates tray icon, starts timer.
  2. Status Check – Queries NUT server or local UPS via WMI.
  3. Tray Icon Update – Changes icon color and tooltip.
  4. Shutdown Logic – Starts countdown on AC loss, shuts down if delay expires.
  5. TCP Server – Sends UPS status as JSON.
  6. Cleanup – Disposes icons and stops TCP listener.

6. Running the Script

Set-ExecutionPolicy RemoteSigned -Scope Process
.\UPSMonitor.ps1

8. Troubleshooting

IssuePossible CauseSolution
Tray icon not visibleScript not runningCheck PowerShell console for errors.
Shutdown not triggeredInsufficient permissionsRun PowerShell as Administrator.
TCP server not workingPort in useChange $tcpPort to an unused port.
NUT server query failsWrong IP/UPS nameVerify $NutServer and $UpsName values.

9. Safety Notes

  • Test without shutdown enabled before production use.
  • Set $shutdownDelaySeconds appropriately to avoid accidental shutdowns.
  • Secure TCP port with firewall rules if enabled.
