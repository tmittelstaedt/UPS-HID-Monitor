UPS Monitor for macOS

This is a Python 3 application for macOS that monitors a connected UPS (Uninterruptible Power Supply) via HIDAPI and displays real‑time status in the macOS menu bar. It also runs a TCP server that outputs the UPS status in JSON format for remote monitoring.

Features

  • Displays UPS status (On AC Power / On Battery) in the macOS menu bar.
  • Colored icons:
    • Green – On AC Power
    • Grey – Unknown - unplugged
    • Red – On Battery
  • Shows battery percentage, runtime remaining, and input voltage.
  • Updates automatically every 5 seconds.
  • Runs a TCP server on port 50000 to serve JSON status to clients.
  • Cross‑version macOS constant handling for compatibility.
  • Explicit PyObjC selector binding to avoid BadPrototypeError.

Requirements

  • macOS 10.9 or later
  • Python 3.8+
  • hidapi Python package
  • pyobjc Python package
pip3 install hidapi pyobjc

Driver Support Requirements

This script communicates with your UPS through Apple's built‑in UPS Power USB driver, which is integrated into macOS and tied into System Preferences → Energy Saver (or System Settings → Battery on newer macOS versions).

If your UPS is not well supported by this Apple driver — for example, if the macOS battery/power icon in the menu bar shows no data, or reports 0V voltage or 0% battery — then this script will also be unable to display correct data. It does not bypass the Apple driver or talk directly to the UPS hardware at a low level.

To check support:

  1. Connect your UPS via USB.
  2. Open System Preferences → Energy Saver (or System Settings → Battery).
  3. Look for UPS information such as battery percentage, runtime, and voltage.

If these values are missing or incorrect, the script will reflect the same limitations.

Automatic Shutdown

Automatic system shutdown is provided by Apple's UPS Power Driver. System Preferences -> Energy Saver -> UPS -> Shutdown Options

Configuring Your UPS ID

Before running the script, you must manually set your UPS's Vendor ID and Product ID in the source code. These IDs tell hidapi which USB device to open.

To find your UPS's IDs, run the following command in Terminal:

python3 - <<'PY'
import hid
for d in hid.enumerate():
    print(f"{d['vendor_id']:04x}:{d['product_id']:04x} {d['manufacturer_string']} {d['product_string']}")
PY

Look for the line that matches your UPS manufacturer and model. The first part (before the space) is in the format vvvv:pppp where:

  • vvvv = Vendor ID (hexadecimal)
  • pppp = Product ID (hexadecimal)

Edit ups_monitor.py and set these values in the open_ups() function where hid.device().open(vendor_id, product_id) is called.

Installation

  1. Clone or download this repository.
  2. Ensure your UPS is connected via USB and recognized by macOS.
  3. Install the required Python packages (see above).
  4. Set your UPS Vendor ID and Product ID in the script (see above).
  5. Make the script executable: 
    chmod +x ups_monitor.py

Usage

  1. Run the script: 
    python3 ./ups_monitor.py
  2. The UPS status icon will appear in the macOS menu bar.
  3. Click the icon to view detailed UPS information or quit the app.
  4. To get JSON status remotely: 
    nc <your-mac-ip> 50000
    or 
    telnet <your-mac-ip> 50000

JSON Output Example

{
    "battery_percent": 95,
    "runtime_minutes": 120,
    "input_voltage": 120.0,
    "timestamp": "2026-08-27T02:15:00.123456",
    "status": "On AC Power"
}

Autostart on macOS Boot

To have the UPS monitor start automatically when you log in:

  1. Open Automator (found in Applications).
  2. Create a new document and choose Application.
  3. From the left panel, search for Run Shell Script and drag it into the workflow.
  4. In the shell script box, enter: 
    /usr/local/bin/python3 /path/to/ups_monitor_macos.py
    Replace /path/to/ups_monitor_macos.py with the full path to your script.
  5. Save the Automator application somewhere (e.g., ~/Applications/UPS Monitor.app).
  6. Open System Settings �~F~R General �~F~R Login Items.
  7. Click the + button and add your saved Automator application.

Troubleshooting

  • If you see BadPrototypeError, ensure you are using the selector‑fixed version of the script.
  • If the JSON output never changes, check that your UPS is supported by hidapi and that the USB cable is connected.
  • If the TCP port is in use, change PORT in the script.
