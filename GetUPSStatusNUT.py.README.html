UPS Menu Bar Monitor - Documentation

This application is a macOS menu bar utility written in Python using PyObjC and AppKit. It connects to a Network UPS Tools (NUT) server to monitor UPS status and display it in the macOS menu bar.

Features

  • Displays a colored ball in the menu bar:
    • Green = UPS Online (OL)
    • Red = UPS On Battery (OB)
    • Gray = No connection or unknown status
  • Dropdown menu with vertical list of UPS stats:
    • Status
    • Battery Charge (%)
    • Runtime (seconds)
    • Device Model
    • Input Voltage (V)
    • Battery Date
  • Automatic shutdown if UPS is on battery for more than a configurable threshold (default: 60 seconds).
  • Quit option in the menu.

Requirements

  • macOS 10.15+ (Catalina or later)
  • Python 3.x
  • PyObjC package
  • Access to a running NUT server

Installation

  1. Install Python 3 if not already installed.
  2. Install PyObjC: 
    pip3 install pyobjc
  3. Save the script (e.g., GetUPSStatusNUT.py) to your desired location.
  4. Ensure you have network access to the NUT server.

Configuration

Edit the following variables in the UPSMenuBarApp class init() method:

self.poll_interval = 5       # seconds between polls
self.ob_threshold = 60       # seconds on battery before shutdown
self.nut_server = "172.16.16.20"
self.ups_name = "nutdev-usb1"
self.username = ""
self.password = ""

Running the Application

python3 GetUPSStatusNUT.py

The colored ball will appear in the macOS menu bar. Click it to see UPS stats and the Quit option.

Note: To allow automatic shutdown without a password prompt, edit the sudoers file: 
sudo visudo
Add: 
yourusername ALL=(ALL) NOPASSWD: /sbin/shutdown

How It Works

  1. Connects to the NUT server via TCP.
  2. Retrieves UPS variables using the LIST VAR command.
  3. Updates the menu bar icon color based on ups.status.
  4. Populates the dropdown menu with UPS stats.
  5. If ups.status is OB for longer than ob_threshold, initiates shutdown.

Customization

  • Change colors in make_colored_ball() method.
  • Add or remove menu items by editing self.menu_items in init().
  • Adjust polling frequency via self.poll_interval.

Troubleshooting

  • AttributeError: 'UPSMenuBarApp' object has no attribute 'start_polling' → Ensure start_polling() is indented inside the class.
  • No UPS data → Check NUT server IP, UPS name, and network connectivity.
  • Shutdown requires password → Update sudoers file as described above.
