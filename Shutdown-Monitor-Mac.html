UPS Status Menu Bar Monitor for macOS

This Python 3 application runs in the macOS menu bar and monitors the status of a UPS (Uninterruptible Power Supply) via a TCP server. It displays a colored icon to indicate UPS status, shows full JSON data in a dropdown menu, and can automatically shut down the Mac if the UPS remains on battery for a configurable delay.

Features

  • Runs in the macOS menu bar (no terminal window required once packaged).
  • Color-coded status icon:
    • Green – UPS Online
    • Red – UPS On Battery (shutdown countdown starts)
    • Yellow – Unknown status
    • Gray – Cannot connect to UPS server
  • Hover tooltip shows short status.
  • Click menu shows full JSON data from the UPS server (read-only, selectable).
  • Automatic shutdown after a set delay if UPS stays on battery.
  • Logs events to ~/Library/Logs/ups-shutdown-monitor.log.

Requirements

  • macOS Catalina (10.15) or newer.
  • Python 3.x installed (macOS 12+ includes python3 by default).
  • PyObjC (usually preinstalled on macOS); if missing, install as the owner (not root) via: 
    
python3 -m pip install --upgrade pip
python3 -m pip install pyobjc

Installation

  1. Save the script as Shutdown-Monitor-Mac.py.
  2. Make sure you have followed proper cr/lf terminations for MacOS if you have modified the script on a Windows system
  3. The following Powershell command will remove carriage returns from a textfile created on Windows you plan on copying with SCP over to a Mac: 
    Get-Content "Shutdown-Monitor-Mac.py.txt" | ForEach-Object { $_ -replace "`r", "" } | Out-File "Shutdown-Monitor-Mac.py" -Encoding UTF8
  4. The following Windows 11 command will copy the Mac-format script over to a Mac: 
    Get-Content "scp Shutdown-Monitor-Mac.py tedmittelstaedt@172.16.100.127:/Users/tedmittelstaedt/Shutdown-Monitor-Mac.py" -Encoding UTF8
  5. On the Mac command line, make it executable: 
    chmod +x ups_menu.py
  6. Edit the configuration section at the top of the script: 
    SERVER_IP = "192.168.1.50"
SERVER_PORT = 50000
CHECK_INTERVAL = 30
SHUTDOWN_DELAY = 300

Running

./ups_menu.py

The icon will appear in the macOS menu bar. Hover to see a short status, click to view full JSON data and access the Quit option.

Packaging as a macOS App

  1. Install py2app: 
    pip3 install py2app
  2. Create a setup.py file: 
    from setuptools import setup

APP = ['ups_menu.py']
OPTIONS = {'argv_emulation': True}

setup(
    app=APP,
    options={'py2app': OPTIONS},
    setup_requires=['py2app'],
)
  3. Build the app: 
    python3 setup.py py2app
  4. Find your app in the dist folder and move it to /Applications.
